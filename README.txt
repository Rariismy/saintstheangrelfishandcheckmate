SAINTS, THE ANGLERFISH, AND CHECKMATE — стартовая версия сайта

ЧТО ВНУТРИ
- index.html — структура сайта
- style.css — оформление и адаптация под телефон/компьютер
- script.js — перелистывание, кнопки и музыка
- images/cover.jpg — ваша обложка
- images/owner-page.png — ваша первая страница
- music/ — сюда нужно положить музыкальный файл

КАК ДОБАВИТЬ МУЗЫКУ
1. Положите скачанную композицию в папку music.
2. Назовите файл soundtrack.mp3.
3. Если у вас файл другого формата, например .ogg или .wav, поменяйте имя файла в строке audio в index.html на фактическое имя и расширение.

КАК ПОМЕНЯТЬ ИКОНКУ МУЗЫКИ
Сейчас стоит временный символ ♫. Когда будет готова ваша картинка-иконка, её можно будет вставить вместо символа в index.html. Само управление музыкой уже подключено.

КАК РАБОТАЕТ НАВИГАЦИЯ
- Компьютер: обложка → разворот (слева ваша страница, справа содержание).
- Телефон: обложка → страница владельца → содержание.
- Нажатие на название раздела открывает временную страницу раздела.
- Кнопка «назад» возвращает к предыдущей логической странице.

ВАЖНО
Пока разделы содержат заглушки — это нормально. Позже добавим в них материалы и оформление.
Для публикации на GitHub Pages загрузите содержимое папки проекта в репозиторий. Главный файл должен называться index.html.
